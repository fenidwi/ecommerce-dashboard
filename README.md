
# E-Commerce Dashboard ✨

## Setup Environment - Python (Windows)
```
Download Python di:
https://www.python.org/downloads/

Saat instalasi:
✔ Centang **Add Python to PATH**

Cek instalasi:
py --version
```

## Install Library
```
py -m pip install streamlit pandas matplotlib seaborn
```

## Alternatif Install
```
pip install streamlit pandas matplotlib seaborn
```

## (Opsional) Jika menggunakan Anaconda
```
conda activate main-ds
pip install streamlit pandas matplotlib seaborn
```

## Run Streamlit App
```
cd dashboard
streamlit run dashboard.py
```

## Akses Dashboard
```
Buka di browser:
http://localhost:8501
```
